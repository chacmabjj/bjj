## Deploy to GitHub Pages

Upload the contents of this folder to the root of the `main` branch of the repository.

Required root files:
- `index.html`
- `styles.css`
- `script.js`
- `robots.txt`
- `site.webmanifest`
- `.nojekyll`
- `assets/`

If GitHub Pages is configured for `Deploy from branch` using `main` and `/root`, the page should publish from the repository root.
